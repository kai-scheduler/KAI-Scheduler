How this estimate works

Cached state estimates cluster objects retained by the scheduler: Pods, workloads, eligible nodes, and inferred BindRequests.

Scheduling reserve covers temporary work for the largest workload, queued demand, and placement complexity. Largest-workload Pods × eligible nodes selects a pressure tier; it is not treated as a retained matrix.

Step 4

Validate before production

  1. Apply the Config patch or update the system that owns the Config.
  2. Run cluster fill, the largest jobs, a submission burst, and cleanup.
  3. Monitor complete-cycle memory, CPU throttling, restarts, and scheduling latency.
  4. Keep the calculated limit until measured peaks support changing it.
